Under the hood

ProcessGraphics path
cs2.exeWine 11 on Rosetta 2, DXMT, Metal
steamwebhelper.exeWine 11 on Rosetta 2, DXVK, MoltenVK, Metal
  • Per-process DLL routing. CS2 gets DXMT from its own folder; Steam's Chromium UI gets DXVK, the only path it draws on. No global overrides.
  • Persistent shader cache. Shaders compile once instead of every match.
  • Display-aware fullscreen. Reads your primary display at every launch. Smooth renders the scaled size, Sharp flips Wine's Retina mode for real pixels.
  • Voice diagnostics. Flags Bluetooth headset mics, switches to the built-in mic in one click, and tests the mic through Wine's own capture path.

Install

  1. Download Vaelos-Silicon.dmg above and drag Vaelos Silicon into Applications.
  2. First launch: this build isn't notarized by Apple yet, so macOS blocks it once. Open System Settings → Privacy & Security, scroll to Security, and click Open Anyway.
  3. Set up installs everything a fresh Mac is missing: Rosetta 2, the Whisky Wine engine, a Windows environment and Steam. About 470 MB and five minutes; macOS asks for your password only if Rosetta 2 is missing.
  4. Log in to Steam, install CS2 when Steam asks (about 60 GB), and press Play.

Verify your download

Check the file is exactly what was published before you open it:

shasum -a 256 ~/Downloads/Vaelos-Silicon.dmg
026fba2428b797729450984993668e311806888bec59481d86560b3b5118f3e4

After installing, the signature and its single entitlement (microphone) can be inspected:

codesign --verify --strict --verbose=2 "/Applications/Vaelos Silicon.app"
codesign -d --entitlements - "/Applications/Vaelos Silicon.app"
  • Hardened runtime, ad-hoc signed. No JIT, no unsigned memory, no DYLD exceptions.
  • Pinned, verified downloads. Whisky and its Wine engine come from Whisky's GitHub releases and are refused unless their SHA-256 matches the hash built into the app. Whisky must also carry its developer's Apple signature.
  • No telemetry. The only downloads are the ones Set up makes, all over HTTPS.
  • No admin password, except macOS's own prompt to install Apple's Rosetta 2 if it's missing.
  • Open source: every line that runs is in the repository. Report issues privately via GitHub Security.

FAQ

Is it safe for my Steam account?

Vaelos never launches CS2 with -insecure, so VAC stays on. Valve doesn't officially support VAC under Wine, though, so play on an account you're comfortable with.

Why does it need Whisky?

Whisky ships a maintained, signed Wine 11 build with DXMT and DXVK. Set up downloads and checks it for you, so there's nothing to install by hand, and Vaelos itself stays a 2 MB download.

My teammates hear static.

That's almost always a Bluetooth headset mic: in our tests it broke up just as badly without Wine. Use the built-in mic for input and keep your earbuds for sound; Vaelos does it in one click.

Why the "Open Anyway" step?

Notarization needs a paid Apple Developer ID. Until then the app is ad-hoc signed; the checksum above proves you have the published file.
